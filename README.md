#  ServiceTitan Marketing Attribution & Revenue Forecasting Engine

An interactive Streamlit application designed for Director-level marketing performance auditing, forensic revenue reconciliation, and predictive financial modeling.

### Core Features
- **Forensic Lead Audit:** Detects vendor over-attribution ("ghost leads") by matching ad logs against verified ServiceTitan records.
- **Unit Economics:** Dynamic calculation of true CAC, LTV, and Margin-Adjusted ROAS.
- **Predictive Analytics:** 95% confidence interval time-series forecasting using `statsmodels` (Holt Linear) and `scikit-learn`.
- **Scenario Planning:** Dynamic budget re-allocation engine for ROI optimization.
